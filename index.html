导入、导出与备份

支持 WPS / Excel 导入并保存到云端数据库；根据角色控制导入导出权限。

① 导入历史达人名单

支持 Excel（.xlsx）和 CSV（.csv），可读取 XLSX 工作簿中具有达人用户名或主页链接的工作表。原始文件不会被修改。同平台用户名或主页链接相同的记录自动跳过，不会覆盖已有内容。

点击选择文件，或直接把文件拖到这里
第一次使用建议先导入全部旧名单

② 导出 WPS 表格（CSV）

导出达人全部字段，使用 UTF-8 BOM，WPS 表格可直接打开。可按平台筛选后分别导出。

③ 完整备份与恢复（推荐）

JSON 可导出团队当前可见的达人数据，并可从旧版本地版导入到云端。请先在旧版导出 JSON 文件；不会自动迁移本地数据。

建议使用最新 Chrome / Edge 浏览器，连接互联网后登录。导入 XLSX 需要浏览器支持 ZIP 解压；旧 .xls 请另存为 .xlsx 或 .csv。
